# Security Policy & Vulnerability Disclosure

## 21 CFR Part 11 & GxP Compliance Context
LabRox LIMS is engineered for clinical laboratories and pharmaceutical diagnostic operations requiring strict compliance with FDA 21 CFR Part 11, HIPAA, and GAMP 5 principles. Security and data integrity are fundamental to all code changes.

## Supported Versions
Only the latest release versions receive active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability in LabRox, **please DO NOT open a public issue**.

Instead, report vulnerabilities privately by emailing:
`security@labrox.io`

Include:
1. Type of issue and affected microservice or component.
2. Step-by-step instructions or proof-of-concept to reproduce the issue.
3. Potential impact on clinical data or audit trails.

## Response & Disclosure Timeline
- **Initial Response:** Within 24 hours acknowledging receipt.
- **Triage & Remediation Plan:** Within 72 hours.
- **Fix & Advisory Release:** Coordinated disclosure after verified patch deployment.
